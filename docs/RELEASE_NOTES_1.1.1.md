# MQ's Decrafting Table 1.1.1

Localization hotfix for Minecraft Bedrock **26.50 / 26.52**. Enable both packs and **Upcoming Creator Features**.

- Complete English, Simplified Chinese and Traditional Chinese translations for batch shortfalls, protected equipment, result instructions, errors and cursor mode messages.
- Shortfall hints now use localized item descriptions, with vanilla item names translated in each player's language. Custom names are preserved and long names are shortened in the hint.
- Each player viewing a shared container receives translations in their own client language.
- All 901 generated intermediate items now have a clear, translated “Decrafting Result” name and instructions for collecting materials.
- Existing hardcoded hints refresh automatically. Hints also refresh when the input changes but the missing quantity stays the same.

The two-slot interface, 901 rules, full-batch requirement and damaged/enchanted equipment protection remain unchanged. Import 1.1.1, activate the updated behavior and resource packs, and re-enter your world. Disable older duplicate/test packs.

适用于基岩版正式版 **26.50 / 26.52**。请同时启用行为包、资源包和 **即将推出的创作者功能**。

- 补齐简体中文、繁体中文、英文的数量不足提示、装备保护提示、产物说明、错误和光标模式消息。
- 提示中的原版物品名称随玩家语言显示；保留自定义名称，过长名称在提示中截短。
- 同一容器中的提示由每位玩家的客户端按各自语言翻译。
- 901 种中介物统一使用本地化的“分解产物”名称，注明放入背包后领取材料。
- 自动刷新旧的硬编码提示；输入物品改变、缺少数量相同时也会正确刷新。

导入 1.1.1，启用更新后的两个包并重新进入世界。两格界面、901 条规则、整份数量要求和损坏/附魔装备保护保持原有行为。
